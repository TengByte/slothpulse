03 / SMALL ENOUGH TO UNDERSTAND
A local pipeline you can inspect.
Gemma handles the language. Python owns the source mapping, output contract, and file writes.
01 →
Collect
Up to eight commits. An optional time window and author filter. A pasted error or trace file.
02 →
Preview & mask
Common credential patterns are masked before inference. Preview the exact context without a model call.
03 →
Generate locally
Inspect Ollama model metadata. Reject remote models. Ask downloaded Gemma for source-keyed JSON.
04
Check & save
Validate required sources and error follow-ups, render three sections, append a timestamped Markdown draft.
What gets checked
Required source keys, known source IDs, source types, error follow-ups, output shape, and the three-section renderer. A rejected plan is retried once; repeated failure saves no digest.
Where judgment stays with you
Commit subjects are partial evidence. A trace alone rarely establishes a root cause. Credential masking covers common patterns and needs review. Source validation cannot establish the truth of a sentence.
